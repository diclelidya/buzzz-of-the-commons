# The Buzzz of the Commons — web prototype

First-person walk through a sonified neighbourhood micro-grid (GameUp Türkiye climate hackathon, November 2026).
three.js, no build step. Point clouds in `pc_ply/` are a 50 % copy of the full export.

Play: https://diclelidya.github.io/buzzz-of-the-commons/

Local: `python -m http.server 8000` in this folder, then open `http://localhost:8000/web/`.
